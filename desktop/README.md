# <img src="build/icon.png" width="40" align="center"/> dopomine для компьютера

Версия [Dopomine](../README.md) для Windows, Linux и macOS: тот же каталог Кинопоиска с рейтингами
Кинопоиска и IMDb, тот же плеер без рекламы и пропуск заставок, но с интерфейсом для большого экрана.
Дизайн — один в один [splicer](https://github.com/D0PXMINE/splicer): его стили, точечные узоры,
иконки и элементы, боковая панель и карточки, светлая и тёмная тема.

## Скачать

Установщики собирает GitHub Actions (workflow **Desktop**) и выкладывает в релиз
[`desktop`](https://github.com/D0PXMINE/Dopomine-film/releases/tag/desktop):

- **Windows** — `Dopomine-Setup-1.0.0.exe` (установщик) или `Dopomine-1.0.0-portable.exe`
  (без установки, просто запустить);
- **Linux** — `Dopomine-1.0.0.AppImage` или `.deb`;
- **macOS** — `Dopomine-1.0.0.dmg`.

Сборки не подписаны сертификатом: Windows SmartScreen покажет «Неизвестный издатель» —
«Подробнее» → «Выполнить в любом случае»; на macOS — правый клик по приложению → «Открыть».

## Что умеет

- главная с вкладками «Фильмы / Сериалы / Аниме» и подборками, каталог с фильтрами, поиск по
  названию, ссылке или ID Кинопоиска (и поиск в интернете — Wikidata — для того, чего нет в каталоге),
  страница фильма с рейтингами, описанием, актёрами и похожими, избранное, история
  и «Продолжить» в боковой панели;
- плеер: озвучки, качество, субтитры, скорость, сезоны и серии, продолжение с места остановки,
  следующая серия, картинка в картинке, полный экран, журнал;
- **пропуск заставок** во всём: кнопка «Пропустить заставку / пересказ», «Следующая серия» на
  титрах, **«Автопропуск»** (в плеере и в настройках), отметки заставок на полосе перемотки;
  разметка — от источника, AniSkip, TheIntroDB, IntroDB или своя («Заставка» → «Здесь начинается…»);
- источники как в Android-версии: AniLiberty и AnimeVost для аниме, VeoVeo, Collaps, остальные
  плееры сайта (поток ловится со скрытой страницы) и, в крайнем случае, сам плеер сайта — с
  заблокированной рекламой, всплывающими окнами и переходами на чужие сайты.

### Клавиши в плеере

| Клавиша | Действие |
|---|---|
| Пробел, K | пауза / продолжить |
| ← / → (с Shift — 30 с) | −10 / +10 секунд |
| ↑ / ↓ | громкость |
| M | звук вкл/выкл |
| F, двойной клик | во весь экран |
| N | следующая серия |
| S | пропустить заставку |
| Esc | закрыть меню, выйти из полного экрана, закрыть плеер |

Ссылки Кинопоиска можно открывать прямо в приложении: `Dopomine.exe https://www.kinopoisk.ru/film/301/`
или ссылкой вида `dopomine://301`.

## Сборка

Нужен Node.js 22.

```
npm ci
npm run dev          # окно с горячей перезагрузкой
npm run build        # dist/
npm test             # unit-тесты (node --test)
xvfb-run -a node test/e2e.mjs [--online] [--site]   # проверка окна через Playwright, с реальными плеерами
npm run dist:win     # release/: portable и zip; установщик NSIS собирается на Windows (или в CI)
npm run dist:linux   # release/: AppImage и deb
```

Каталог (`resources/catalog.db`), список блокировки рекламы и скрипты для страницы плеера берутся
из Android-приложения (`../app/src/main/assets`) при сборке — данные одни на обе версии.

## Устройство

- `src/main/` — процесс Electron: каталог (`catalog.ts`, sql.js), библиотека и настройки
  (`store.ts`, JSON в папке данных), источники (`resolve/`), пропуск заставок (`skip.ts`),
  заголовки и CORS для видеозапросов (`media.ts`), страница плеера в скрытом окне и поверх плеера
  (`site.ts`);
- `src/renderer/` — окно на React: стили, узоры и элементы splicer, экраны (`views/`), плеер на
  hls.js (`player/`);
- `src/shared/` — типы и правила разметки заставок, общие для обоих процессов.
