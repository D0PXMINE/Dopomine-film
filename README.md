# Dopomine

Android-приложение для просмотра фильмов и сериалов: каталог Кинопоиска с рейтингами
Кинопоиска и IMDb, избранное, история и встроенный плеер без рекламы.
Плеер — тот же, что открывал userscript для Tampermonkey (`<зеркало>/<ID Кинопоиска>`),
только внутри приложения.

**Скачать APK:** [`release/Dopomine-1.0.0.apk`](release/Dopomine-1.0.0.apk) (Android 7.0+).

## Возможности

- **Главная**: отдельные подборки для фильмов и для сериалов (переключатель «Фильмы / Сериалы»):
  популярное, новинки, Топ-250, жанровые полки, тематические коллекции Кинопоиска.
  Подборки подгружаются по мере прокрутки, чтобы экономить лимит запросов.
- **Каталог**: все фильмы, сериалы, мини-сериалы и ТВ-шоу с фильтрами по жанру, годам,
  минимальному рейтингу и сортировкой (популярные / по рейтингу / новые), бесконечная прокрутка.
- **Поиск** по названию с подсказками недавних запросов. Можно вставить ссылку на Кинопоиск
  или просто ID — приложение откроет фильм. Ссылки Кинопоиска можно «Поделиться → Dopomine».
- **Рейтинги** Кинопоиска и IMDb на каждой карточке и крупно на странице фильма (с числом оценок).
- **Страница фильма**: описание, страны, жанры, длительность, возраст, актёры и режиссёр,
  сезоны и серии для сериалов, похожие фильмы.
- **Избранное** (закладка на странице фильма) и **история** с прогрессом просмотра.
- **Плеер** (по функциям в духе Zona, без подписок и рекламы):
  - открывается внутри приложения, сразу в горизонтальном режиме на весь экран;
  - со страницы плеера убрано всё, кроме самого видео;
  - блокировка рекламы: ~19 тыс. рекламных и трекинговых доменов, VAST/VPAID-запросы
    видеорекламы, всплывающие окна, переходы на сторонние сайты, `alert`-диалоги;
    кнопки «Пропустить рекламу» нажимаются автоматически;
  - выбор источника (Alloha, Collaps, Turbo и др.) в нативном меню «Источник»;
    озвучка, качество, сезон и серия выбираются в самом плеере;
  - продолжение с места остановки (для фильмов и для каждой серии) и полка
    «Продолжить просмотр» на главной;
  - жесты: свайп по левой половине — яркость, по правой — громкость;
  - картинка в картинке (PiP) с кнопкой паузы, экран не гаснет во время просмотра;
  - меню приложения открывается свайпом вниз от верхнего края или стрелкой сверху.

## Первый запуск: API-ключ Кинопоиска

Каталог, рейтинги и описания берутся из [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech).
Ключ бесплатный: зарегистрируйтесь на сайте, скопируйте ключ из профиля и вставьте его
при первом запуске (или позже в «Настройки → Кинопоиск API»). Приложение кэширует ответы,
чтобы не тратить дневной лимит бесплатного ключа.

Можно сразу «зашить» свой ключ в сборку — тогда вводить его не придётся:

```
# local.properties
KP_API_KEY=ваш-ключ
```

или переменная окружения `KP_API_KEY` / секрет репозитория `KP_API_KEY` для GitHub Actions.

## Если плеер сменил адрес

Сайты-плееры периодически меняют зеркала. Новый адрес указывается в
«Настройки → Плеер → Адрес плеера». По умолчанию — `https://fz7-16gs81j.troutcdn.site`, как в скрипте.

## Сборка

Нужны JDK 17+ и Android SDK (platform 35).

```
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest        # unit-тесты и проверка экранов в Robolectric
./gradlew recordRoborazziDebug     # скриншоты экранов в app/build/outputs/roborazzi
```

GitHub Actions собирает APK на каждый push (артефакт `Dopomine-apk`).

Подпись: если рядом лежит `keystore.properties` (`storeFile`, `storePassword`, `keyAlias`,
`keyPassword`), release подписывается вашим ключом; иначе — ключом `app/debug.keystore`
из репозитория, чтобы любые сборки ставились поверх друг друга.

## Устройство

- Kotlin, Jetpack Compose (Material 3), Navigation, ViewModel, Room (избранное, история,
  позиции просмотра), DataStore (настройки), Retrofit + OkHttp (с дисковым кэшем
  ответов API), Coil (постеры), AndroidX WebKit (плеер).
- Плеер: `player/PlayerActivity.kt` — WebView со встроенными скриптами
  `assets/player/top.js` (оставляет на странице только плеер) и `assets/player/frames.js`
  (работает во всех фреймах: меню источников, прогресс, автопропуск рекламы).
  Список блокировки — `assets/adblock/hosts.txt` (Peter Lowe's list, AdAway, RU AdList, CC BY 3.0).
- Для WebView плеера отключён Safe Browsing: зеркала видеосайтов часто попадают в эти списки,
  и предупреждение Google закрывало бы плеер. Переходы со страницы плеера на другие сайты заблокированы.
- Иконка генерируется скриптом `tools/gen_icons.py`.
