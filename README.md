# <img src="app/src/main/res/mipmap-xxxhdpi/ic_launcher.png" width="44" align="center"/> dopamine

Android-приложение для фильмов, сериалов и аниме: каталог Кинопоиска с рейтингами Кинопоиска
и IMDb, избранное, история и свой плеер без рекламы. Ключи, регистрация и подписки не нужны.
Дизайн — как у [splicer](https://github.com/D0PXMINE/splicer): монохром, светлая и тёмная тема,
Geist и Geist Mono, узоры из точек.

**Скачать APK:** [`release/Dopamine-2.4.0.apk`](release/Dopamine-2.4.0.apk) (Android 7.0+).
Версия для компьютера (Windows, Linux, macOS) — в папке [`desktop/`](desktop/README.md),
установщики — в релизе [`desktop`](https://github.com/D0PXMINE/Dopomine-film/releases/tag/desktop).

До версии 2.4.0 приложение называлось Dopomine: новая версия ставится поверх него, избранное,
история и настройки сохраняются.

С версии 2.2.1 APK подписан новым ключом автора. Если стоит 2.2.0 или старше, удалите приложение
перед установкой (избранное и история при этом сотрутся); дальше новые версии ставятся поверх.

## Плеер: откуда берётся видео

Сайт из скрипта (`https://fz7-16gs81j.troutcdn.site/<ID Кинопоиска>`) сам видео не хранит: он
встраивает выбор плееров (linkpp.ink), а тот спрашивает у `p.linkpp.ink/api/players` список
балансеров — Alloha, Collaps, Turbo, Vibix — и открывает один из них в iframe (VeoVeo приложение
не предлагает). Приложение идёт тем же путём, но берёт сам поток и играет его в своём плеере (ExoPlayer):

1. **Collaps** — его страница содержит ссылки на поток, названия озвучек, субтитры и все серии
   (тот же код, что сайт подгружает скриптом `actualize.js`). HLS у Collaps доходит только до 720p,
   а DASH того же видео — до 1080p, поэтому играет DASH; если устройство его не потянет, плеер сам
   переключится на HLS.
2. **Остальные плееры** (Alloha, Turbo…) — страница плеера сначала открывается невидимо, приложение
   само нажимает «▶» и перехватывает адрес видеопотока вместе с нужными заголовками. Манифест
   узнаётся и по адресу, и по содержимому ответа (даже за перенаправлением и без расширения).
   Если за 10 секунд поток не появился (например, у Turbo проверка «не робот» отвечает медленно),
   страница плеера показывается как есть: нажмите в ней «▶» — приложение подхватит поток и
   переключится на свой плеер. Ролик короче 4 минут считается рекламой: приложение ждёт сам фильм.
3. Если поток так и не пойман — играет плеер страницы, очищенный от рекламы, всплывающих окон
   и переходов на чужие сайты.

Список плееров сайта загружается параллельно с прямыми источниками, у каждого источника свой
тайм-аут, поэтому медленный сайт или источник больше не задерживает запуск.

## Аниме

На главной и в каталоге есть вкладка «Аниме» (около 1700 тайтлов: всё, у чего в Wikidata есть
ID MyAnimeList, и японская анимация). Для аниме плеер сначала пробует две команды озвучки
с открытыми API, потом обычные источники:

1. **AniLiberty (AniLibria)** — HLS в 1080p, 720p и 480p, все сезоны франшизы по порядку.
   Релиз находится точно по ID MyAnimeList, иначе по названию и году.
2. **AnimeVost** — MP4 в 720p и 480p; сезоны собираются из его релизов
   («… (второй сезон)», «… 2nd Season»).
3. Дальше Collaps и остальные — там обычно много других озвучек.

Источник можно сменить вручную кнопкой «Источник». Кнопка «Журнал» показывает, что именно
делал плеер, — пригодится, если какой-то фильм не запускается.

## Пропуск заставок

В фильмах, сериалах и аниме, в своём плеере и в плеере сайта:

- кнопка «Пропустить заставку» / «Пропустить пересказ», на титрах сериала — «Следующая серия»;
- **«Автопропуск»** (кнопка в плеере и переключатель в настройках): заставки и пересказы
  пропускаются сами, на титрах через 5 секунд включается следующая серия; «Вернуть» отменяет;
- разметка берётся у источника (AniLiberty отдаёт начало и конец опенинга) и из открытых баз
  [TheIntroDB](https://theintrodb.org), [IntroDB](https://introdb.app) (по IMDb ID) и
  [AniSkip](https://aniskip.com) (аниме по ID MyAnimeList);
- у AniSkip берутся все разметки, а не только сделанные на видео ровно той же длины, и из них —
  разметка самой близкой по длине версии (раньше из-за разницы в несколько секунд не находилось
  ничего); титры более короткой версии сдвигаются на разницу;
- если в каталоге у аниме нет ID MyAnimeList (так у многих популярных: «Клинок, рассекающий
  демонов», «Магическая битва», «Реинкарнация безработного»…), он находится на Shikimori по
  названию и году, а сезоны источника сопоставляются с сезонами MyAnimeList по числу серий:
  второй сезон «Клинка» у источников — это две записи MyAnimeList (7 + 11 серий);
- если именно эта серия не размечена, берётся заставка соседних серий, когда они совпадают
  (с точностью до нескольких секунд);
- для потока, пойманного со страницы плеера, сезон и серия читаются с самой страницы (выбранный
  пункт списка, подсвеченная кнопка, заголовок или адрес плеера); у сериала с одним сезоном
  достаточно номера серии. Если сезон неизвестен, заставка другого сезона не подставляется;
- если разметки нет, заставку можно отметить самому («Заставка» → «Здесь начинается / заканчивается
  заставка»), и она будет пропускаться во всех сериях этого сериала.

**Возможности плеера (как в Zona):** выбор озвучки, качества, субтитров и скорости; список
сезонов и серий, кнопка и автозапуск следующей серии; продолжение с места остановки для
каждого фильма и каждой серии; двойной тап — ±10 секунд; свайпы: слева яркость, справа
громкость, по горизонтали перемотка; режимы «вписать / заполнить / растянуть»; картинка в
картинке; экран не гаснет.

## Каталог без ключей

Каталог лежит прямо в приложении (около 100 тысяч фильмов и сериалов) и работает офлайн:
поиск, фильтры по жанрам, годам и рейтингу, подборки на главной.

- названия, годы, жанры, страны, длительность, IMDb и MyAnimeList ID — **Wikidata** (CC0);
- рейтинги и число оценок Кинопоиска и IMDb — `rating.kinopoisk.ru` (публичный XML);
- постеры — CDN Кинопоиска по ID фильма;
- описания — русская **Википедия**, для аниме — **Shikimori**; актёры и режиссёры — Wikidata.
  С 2026 года Википедия ограничивает запросы безымянных клиентов (10 в минуту на адрес, а у мобильных
  операторов один адрес на тысячи людей), поэтому приложение представляется своим именем — так
  лимит 200 запросов в минуту. Описание, актёры и свежие рейтинги загружаются независимо друг от друга.

Новинки, которых ещё нет в снимке, находятся кнопкой «Искать в интернете» в поиске, а любой
фильм открывается по ссылке Кинопоиска или ID (в поиске или через «Поделиться → Dopamine»).
В поиске можно оставить только фильмы, сериалы или аниме (кнопки «Все · Фильмы · Сериалы · Аниме»).

Снимок пересобирается раз в неделю (GitHub Actions, workflow **Catalog**) и публикуется в
релизе `catalog`; приложение само скачивает свежую версию и подключает её при следующем
запуске. Если Кинопоиск при сборке не ответил по какому-то фильму, берётся рейтинг из прошлого
снимка (раньше такие фильмы теряли рейтинг и падали в списках). Приложение не ставит снимок, в
котором пропали рейтинги у известных фильмов (из 1000 самых оцениваемых должно остаться не меньше 98%).

## Если плеер сменил адрес

Сайты-плееры меняют зеркала. Новый адрес указывается в «Настройки → Плеер → Адрес плеера».

## Сборка

Нужны JDK 17+ и Android SDK (platform 35).

```
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest        # unit-тесты и проверка экранов в Robolectric
./gradlew recordRoborazziDebug     # скриншоты экранов в app/build/outputs/roborazzi
./gradlew testDebugUnitTest --tests '*OnlineSourcesTest' -Ddpm.online=true   # проверка плееров по сети

python3 tools/catalog/build_catalog.py --out app/src/main/assets/catalog/catalog.db   # пересобрать каталог
python3 tools/gen_icons.py                                                           # пересобрать иконку
```

GitHub Actions собирает APK на каждый push (артефакт `Dopamine-apk`).

Подпись: ключ автора в репозиторий не кладётся. Локально release подписывается ключом из
`keystore.properties` в корне проекта (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`),
в GitHub Actions — из секретов `SIGNING_KEYSTORE` (файл ключа в base64) и `SIGNING_PASSWORD`.
Без ключа release подписывается отладочным ключом этой машины: такой APK ставится, но не поверх
официального.

## Устройство

- Kotlin, Jetpack Compose, Navigation, Room (избранное, история, позиции), DataStore,
  OkHttp, Coil, Media3 ExoPlayer (HLS/DASH), AndroidX WebKit.
- `player/resolve/` — Collaps, AniLiberty, AnimeVost и список плееров сайта; `player/WebPlayer.kt` — сайт
  в WebView (перехват потока, блокировка рекламы, `assets/player/*.js`; проверка в Chromium —
  `node desktop/test/frames.mjs`);
  `player/PlayerActivity.kt` и `player/ui/PlayerScreen.kt` — плеер.
- `data/catalog/` — офлайн-каталог (SQLite из `assets/catalog`), обновление и онлайн-источники.
- Иконка: восьмилучевая звезда — тонкие лучи плавно расходятся из круглого центра
  (`tools/gen_icons.py`). Шрифты Geist / Geist Mono (SIL OFL).
- Список блокировки рекламы — `assets/adblock/hosts.txt` (Peter Lowe's list, AdAway, RU AdList, CC BY 3.0).
- Для WebView плеера отключён Safe Browsing: зеркала видеосайтов часто попадают в эти списки,
  и предупреждение закрывало бы плеер. Переходы со страницы плеера на другие сайты заблокированы.
